Upute po aplikaciji

Google Kalendar

Klikni Dodaj u Google Kalendar gore. Ili ručno: Google Kalendar → Ostali kalendari → + → Pretplati se putem URL-a → zalijepi https://marinfrankovic.github.io/Linigra-26-27-A/linigra-1a.ics.

iPhone / iPad / Mac

Klikni Dodaj u Apple Kalendar i potvrdi. Ručno na iPhoneu: Postavke → Aplikacije → Kalendar → Računi → Dodaj račun → Ostalo → Dodaj kalendar pretplate → zalijepi adresu.

Outlook (web i novi Outlook)

Kalendar → Dodaj kalendar → Pretplati se s weba → zalijepi https://marinfrankovic.github.io/Linigra-26-27-A/linigra-1a.ics → daj mu ime i spremi.

Outlook (klasični, samo uvoz)

Pretplata se osvježava sama, uvoz ne. Ako ipak želiš uvoz: File → Open & Export → Import/Export → Import from another program or file → Comma Separated Values → odaberi linigra-1a.csv.
